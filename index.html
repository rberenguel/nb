How to Play

Dual N-Back is a memory and attention training game. You must remember if the current position and color match what you saw N steps ago.

Setup

Select level: Click any square (1-9) to set N-back level

Toggle mode: Click the same square again to switch between Dual (2) and Triple (3) modes

Start: Click the level number at top or anywhere in the bottom

Playing

Position: Press left edge if position matches N steps ago

Color: Press right edge if color matches N steps ago

Letter (Triple): Press bottom if letter matches N steps ago

Press again to toggle off. You can answer multiple dimensions per round.

Feedback

Green flash: Correct answer

Red flash: Wrong answer

Brain/battery fills: Your progress through 100 rounds (100 rounds are around 5 minutes)

Controls

Touch/mouse: Edges

Keyboard: Z (position) / X (letter) / C (color)

Space: Start game / Pause / Resume

? key: Show this help

Escape: Close any modal

Restart: Click restart icon (↺) when paused
